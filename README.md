# 智练题库

一个无需构建步骤的静态刷题网站，适合部署到 GitHub Pages。

## 已实现

- 两套试卷入口，固定为单选、多选、判断三种题型的答题顺序。
- 每次开始练习会随机重排同题型内的题目，并随机重排单选、多选的选项。
- 多选题支持多项勾选；交卷后自动统计得分，并显示每题答案回顾。
- 浏览器本地保存最近 10 次练习记录，不需要数据库或账号。
- 练习过程中可点击“保存并返回”，之后从试卷卡片继续练习；题目顺序和已选答案都会保留。
- 交卷后可筛选错题并查看每道题的答案解析，历史记录也支持再次打开错题回顾。

## 本地预览

在项目目录运行：

```powershell
python -m http.server 4173
```

浏览器访问 `http://localhost:4173`。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，然后将本目录的文件上传或推送到 `main` 分支根目录。
2. 打开仓库的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/(root)`，保存。
5. GitHub 生成的 Pages 地址通常为 `https://<你的用户名>.github.io/<仓库名>/`。

## 题库维护

题库在 [questions.js](questions.js) 中，界面和评分逻辑在 [app.js](app.js) 中。每一题均使用以下数据结构：

```js
single(1, '题干', ['选项 A', '选项 B', '选项 C', '选项 D'], 'A')
multiple(1, '题干', ['选项 A', '选项 B', '选项 C'], ['A', 'C'])
trueFalse(1, '判断题干', true)
```

两套试卷均按 30 道单选、10 道多选、20 道判断录入，交卷满分为 100 分。题目数据同时保存标准答案和解析字段，后续可以直接替换解析文本。
